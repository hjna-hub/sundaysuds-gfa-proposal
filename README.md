# SundaySuds × NAVER GFA — Growth Proposal

GitHub Pages에서 바로 열 수 있는 **10페이지 정적 HTML 제안서**입니다. 프레임워크 및 빌드 작업이 필요 없습니다.

## GitHub 업로드

1. GitHub에서 새 공개 저장소(repository)를 생성합니다.
2. 이 폴더의 `index.html`을 저장소 **최상위 경로(root)**에 업로드하고 Commit합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch는 **main**, 경로는 **/(root)**를 선택한 뒤 Save합니다.
5. 배포되면 `https://계정명.github.io/저장소명/#page-1`로 접속할 수 있습니다.

## 사용법

- 좌우 방향키 또는 화면 하단 좌·우 버튼으로 이동
- 상단 **목차**에서 원하는 슬라이드로 바로 이동
- 상단 **PDF 저장**에서 인쇄 대화상자의 **PDF로 저장**, **가로 방향**, **배경 그래픽 포함** 선택
- `#page-6`처럼 주소 뒤 해시를 바꾸면 특정 페이지로 바로 진입
- 모든 내용·디자인은 `index.html`에서 직접 수정 가능

## 제출 전 체크리스트

- 시장 규모·경쟁사 점유율 등 **검증되지 않은 수치를 사용하지 않았습니다**.
- 타게팅 키워드는 운영 설계를 설명하기 위한 **예시**입니다.
- 경쟁사 구매자를 직접 타게팅하는 것으로 설명하지 않았습니다.
- 스토어 타겟은 자사 **네이버 스마트스토어/브랜드스토어 사용 가능 조건**을 확인해야 합니다. 사용이 어려우면 자사몰 리타게팅 대안을 검토하세요.
- 광고주 실제 광고 계정의 성과 / GA4 또는 픽셀 데이터 / 경쟁사 리스트 / 최신 혜택을 확보한 뒤 최종 확정하는 것이 좋습니다.
